diagrams, verified project facts, reference records, and genuine browser
captures for the BOTANICA crop disease classification project.

## Evidence and scope

The project files and saved model metadata were inspected without running
training. Training metrics are identified as previously supplied results
because no training log was found for independent reproduction. Existing
genuine screenshots and a saved diagnosis PDF are included. After the audit,
the app was started with the project virtual environment; the homepage
rendered and reported the model loaded with 38 categories. The PDF download
button was not re-triggered during that audit. See the screenshot checklist
for evidence boundaries.

These materials do not change the Streamlit application, dataset, model, or
recovery checkpoints.
